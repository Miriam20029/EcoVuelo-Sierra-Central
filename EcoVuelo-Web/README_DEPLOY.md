# EcoVuelo Web corregido

Esta versión reproduce la interfaz y las respuestas del cuaderno `EcoVuelo_Sierra_Central.ipynb.ipynb` en una aplicación estática para GitHub Pages.

## Archivos que debes subir o reemplazar

En el repositorio `EcoVuelo-Sierra-Central`, sube en la raíz:

- `index.html`
- `styles.css`
- `app.js`

Cuando GitHub pregunte si deseas reemplazar los archivos anteriores, confirma el cambio.

## Fotografías

La aplicación reconoce automáticamente estas dos estructuras:

- `imagenes/banos.jpg`
- `imágenes/baños.jpg`

También reconoce los demás archivos: `latacunga.jpg`, `salcedo.jpg`, `ambato.jpg`, `riobamba.jpg` y `guaranda.jpg`.

## Publicar con GitHub Pages

1. Entra en **Ajustes**.
2. Abre **Pages**.
3. Selecciona **Implementar desde una rama**.
4. Rama: **principal**.
5. Carpeta: **/(raíz)**.
6. Presiona **Guardar**.
