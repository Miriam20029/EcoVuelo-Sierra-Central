# Publicar EcoVuelo con GitHub Pages

No necesitas crear otro repositorio. Usa el repositorio actual `EcoVuelo-Sierra-Central`.

## Archivos que debes subir a la raíz

- `index.html`
- `styles.css`
- `app.js`

Mantén también:

- `EcoVuelo_Sierra_Central.ipynb`
- `LÉAME.md`
- la carpeta de fotografías (`imagenes` o `imágenes`)

El código admite las dos formas de carpeta y también reconoce `banos.jpg` o `baños.jpg`.

## Activar GitHub Pages

1. Abre el repositorio.
2. Entra en **Ajustes**.
3. En el menú izquierdo entra en **Pages**.
4. En **Origen**, selecciona **Implementar desde una rama**.
5. En **Rama**, selecciona `principal` y la carpeta `/(raíz)`.
6. Presiona **Guardar**.
7. Espera unos minutos.

La dirección será:

`https://miriam20029.github.io/EcoVuelo-Sierra-Central/`
